# Configuration Claude pour GitLab Deployment Manager

Ce dossier contient des commandes personnalisées pour faciliter le développement de l'application Spring Boot.

## Commandes disponibles

### Build et Exécution
- `/build` - Compile le projet avec Maven
- `/run` - Lance l'application en mode développement
- `/test` - Exécute les tests
- `/package` - Crée le JAR exécutable

### Configuration
- `/check-config` - Vérifie la configuration de l'application

### Génération de code
- `/add-controller` - Crée un nouveau contrôleur Spring
- `/add-service` - Crée un nouveau service Spring

### Analyse
- `/analyze-dependencies` - Analyse l'arbre des dépendances Maven

## Utilisation

Tapez simplement `/` suivi du nom de la commande dans Claude Code pour l'exécuter.

Exemple : `/build` pour compiler le projet.
