---
description: Aide à créer un nouveau contrôleur Spring Boot
---

Crée un nouveau contrôleur Spring REST ou MVC dans le package approprié. Demande :
- Le nom du contrôleur
- Le type (REST API ou MVC avec Thymeleaf)
- Le mapping de base
- Les endpoints principaux à créer

Génère le contrôleur avec les annotations appropriées (@RestController ou @Controller, @RequestMapping, etc.).
